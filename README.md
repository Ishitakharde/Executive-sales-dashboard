# Executive Sales Dashboard | Power BI

## Project Overview
Developed an interactive Executive Sales Dashboard using Microsoft Power BI to analyse sales performance across different countries, product categories, sales channels, and time periods.

The dashboard provides a consolidated view of key business metrics to support performance monitoring and data-driven decision-making.

## Key Performance Indicators (KPIs)
- Total Revenue: 645.22K
- Total Gross Profit: 296.38K
- Gross Margin: 45.94%
- Total Orders: 3K
- Total Quantity: 7K

## Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Modelling
- Data Visualization

## Data Modelling & DAX
- Created a dedicated Date Table for time-based analysis.
- Created a separate Measures Table to organise DAX calculations.
- Developed DAX measures for:
  - Total Revenue
  - Total Gross Profit
  - Gross Margin
  - Total Orders
  - Total Quantity

## Dashboard Features

### 1. Sales Performance Analysis
- Monthly Revenue and Gross Profit trends.
- Comparison of sales performance over time.

### 2. Country-wise Analysis
- Top 5 countries by revenue.
- Bottom 5 countries by revenue.

### 3. Sales Channel Analysis
- Revenue contribution from Online Store, Corporate, Retail Partners, and Marketplace.

### 4. Product Category Analysis
- Revenue distribution across Hiking, Camping, Travel, Cycling, and Fitness categories.

### 5. Interactive Filters
- Month
- Quarter
- Product Category
- Country
